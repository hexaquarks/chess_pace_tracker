# Frontend

The React and TypeScript client for Chess Pace Tracker. It collects analysis parameters, displays live processing progress over WebSockets, and renders the pace trend and supporting statistics.

## Development

From this directory:

```bash
npm install
npm start
```

The app runs at `http://localhost:3000` and expects the Rust backend at `http://localhost:8000`.

For the full project overview and backend setup, see the [root README](../README.md).
